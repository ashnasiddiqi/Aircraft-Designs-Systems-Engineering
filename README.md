# Aircraft-Designs-Systems-Engineering

**Project Objective:**

Create a conceptual design of a two-seat, flight trainer aircraft. This project will investigate aircraft configurations, characteristics, modifications, weight and balance proportions, and performance. The project will apply systems engineering methodologies including requirement development, functional analysis, risk assessment, systems architecture, verification planning, and validation. 

**Initial Aircraft Configuration:**

Aircraft type: Primary flight trainer
Occupants: Two
Propulsion: Single piston engine with tractor propeller
Wing configuration: High-wing
Landing gear: Fixed tricycle
Tail configuration: Conventional
Cockpit configuration: side-by-side seating
Flight controls: Conventional mechanic controls

**Project Scope**

The project will cover conceptual aircraft design, rudimentary engineering calculations, aircraft modeling, subsystem architecture, and systems engineering documentation. The design is intended as an educational conceptual study to demonstrate knowledge.
